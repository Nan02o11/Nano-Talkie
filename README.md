# Nano-Talkie
Hi, the project "Nano-Talkie" is a talkie-walkie so tiny that you can attach it on your keys and have a talkie walkie with a range that can go up to (in theory) +4km
and with an autonomy of +1h30 in your pocket.

As you will see, the v1 isn't really tiny enough to be attach to your key but it is simply a ressource problem that I have, I could reduce the size so much by using almost only SMD component and do a real 2 layers PCB, actually the size of it could be the size of the radio module(36mmx20mm) with a thickness of around 1cm(or in the worse case 1.5cm).But I dont have hot station and I don't have a big budget so buy a hot station and buy and buy components+pcb for the projects while finishing my others projects is a bit difficult but I will try to make a V2 very tiny as fast as possible(and make it working, because I didn't even physically build the v1 because I can't buy the components so I don't even know if the v1 work)
